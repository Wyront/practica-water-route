# Что исправлено

## Вход / выход / регистрация
- **Выход из аккаунта** (кнопка «Выход» в шапке): запрос подтверждения, удаление сохранённого входа («Запомнить меня»), возврат на экран входа без перезапуска приложения.
- **Регистрация клиента** работала как макет. Теперь: проверка ФИО, e-mail, телефона, пароля (от 8 символов) и подтверждения, понятные сообщения об ошибках («E-mail уже зарегистрирован»), после успеха e-mail подставляется в окно входа.

## Меню администратора
- **Пользователи**: список из БД, создание (любая роль, пароль хешируется bcrypt), редактирование (ФИО, e-mail, телефон, роль, активность, новый пароль), сброс пароля, деактивация и обратная активация, F5 — обновить.
- **Справочники** (способы оплаты, типы воды и тары, товары, склады, автомобили): загрузка из БД, создание, редактирование, деактивация/активация. Раньше кнопки показывали заглушки.

## База данных
- `patch_002_admin.sql` (запускать после `procedures.sql`):
  - добавлены процедуры `sp_user_update` и `sp_directory_list`;
  - исправлена ошибка, из-за которой **смена роли и деактивация пользователя падали** («Data truncated for column 'target_type'»): триггеры аудита писали значение `user`, которого не было в ENUM таблицы `notes`. Исправлено и в `schema.sql`.
- Порядок импорта: `schema.sql` → `seed.sql` → `procedures.sql` → `triggers.sql` → `patch_001_auth.sql` → `patch_002_admin.sql`.

## Прочее

- Общий код: `Infrastructure/UiErrors.cs` (проверки и показ ошибок), `BaseEditForm` теперь поддерживает асинхронное сохранение.
