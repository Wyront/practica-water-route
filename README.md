# WaterRoute — Доставка питьевой воды

Десктоп-приложение WinForms для управления доставкой питьевой воды по Санкт-Петербургу.

## Архитектура

```
WaterRoute.sln
├── WaterRoute/                 # C# WinForms приложение
│   ├── Forms/                  # Окна и модальные формы
│   ├── Controls/               # Пользовательские контролы (страницы)
│   ├── Models/                 # DTO, enum, настройки БД
│   ├── Services/               # Бизнес-логика, CSV/PDF экспорт, аутентификация
│   ├── Controls/               # Страницы (Dashboard, Catalog, Monitor, Reports, Map, и т.д.)
│   ├── Infrastructure/         # Репозитории, DI, уведомления, карта, сессия
│   └── Database/               # SQL-скрипты (schema, seed, procedures, triggers, README)
├── SmokeTests/                 # Автоматические проверки CSV/PDF/SQL
└── PLAN.md                     # План реализации
```

## Технологии

| Компонент | Технология |
|-----------|------------|
| UI | C# WinForms (.NET 10) |
| БД | MySQL 8.0 |
| ORM/доступ | ADO.NET (MySqlConnector), только `CALL sp_...` |
| Карта | Mapsui.WindowsForms + OpenStreetMap (онлайн) |
| PDF-экспорт | Microsoft Print to PDF (без внешних библиотек) |
| CSV | Собственный парсер с поддержкой кавычек и `;` |
| Пароли | bcrypt (BCrypt.Net-Next) |
| DI/Хост | Microsoft.Extensions.Hosting / DependencyInjection |

## Роли

| Роль | Основные функции |
|------|------------------|
| Администратор | Пользователи, справочники, просмотр, отчёты |
| Диспетчер | Клиенты, заказы, очередь распределения, маршруты, монитор, чат, проблемы |

## Быстрый старт

### 1. База данных

```bash
# Установка MySQL 8.0 и MySQL Workbench
# Развёртывание схемы и данных
mysql -u root -p < WaterRoute/Database/schema.sql
mysql -u root -p < WaterRoute/Database/seed.sql
mysql -u root -p < WaterRoute/Database/procedures.sql
mysql -u root -p < WaterRoute/Database/triggers.sql
```

### 2. Конфигурация

В `WaterRoute/appsettings.json`:

```json
{
  "Database": {
    "Server": "localhost",
    "Port": 3306,
    "Database": "waterroute",
    "UserId": "root",
    "Password": "",
    "SslMode": false
  }
}
```

### 3. Запуск

```bash
dotnet run --project WaterRoute/WaterRoute.csproj
```

## Основные возможности

| Модуль | Функции |
|--------|---------|
| **Администратор** | Пользователи/роли, справочники, просмотр, отчёты |
| **Диспетчер** | Клиенты/адреса, заказы/очередь, планировщик (1 заказ = 1 маршрут), монитор, чат/проблемы, отчёты |
| **Кладовщик** | Остатки/резервы, поступления/списания/корректировки, тара (подтверждение/долги), импорт CSV, отчёты |
| **Курьер** | Маршруты, выполнение/недоставка, возврат тары, чат с диспетчером, проблемы, отзывы |
| **Клиент** | Профиль/адреса, каталог/корзина/оформление, история/повтор/отмена, карта/диспетчер, отзывы/PDF |

## Импорт / Экспорт

| Функция | Формат | Особенности |
|---------|--------|-------------|
| Импорт товаров | CSV (`;`) | Шаблон, проверка колонок/дублей/чисел/ФК, all-or-nothing |
| Импорт поступлений | CSV (`;`) | Склад + артикул + кол-во + комментарий, all-or-nothing |
| Экспорт отчётов | CSV / PDF | Один файл на отчёт, русский текст, нумерация страниц в PDF |
| PDF генерация | Microsoft Print to PDF | Без внешних библиотек, русский текст, разбивка по страницам |

## Карта

- Онлайн: Mapsui + OpenStreetMap (тайлы загружаются в runtime)
- Маркеры склада и адреса, линия маршрута
- Offline-режим **не реализован** в текущем этапе (решение от 26.11.2026)
- При потере связи — окно вызова диспетчера с телефоном

## Ограничения текущего этапа

- **Только desktop WinForms** — REST API, мобильное приложение, JWT, Postman — не входят.
- **Offline-карта** исключена (решение от 26.11.2026). Онлайн-карта работает, при потере связи — окно вызова диспетчера.
- **Реальные платежи** не подключены. Способ оплаты — справочник.
- **Частичная доставка** исключена. Принцип «всё или ничего».
- **REST API, JWT, мобильное приложение, Postman** — будущие этапы.
